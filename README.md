# 🦆⚡ Pato Guloso — Maré Elétrica

## ⬇ [BAIXAR O MOD (0.80.1)](https://github.com/patinho8/pato-guloso/raw/main/baixar/mare-eletrica-0.80.1.jar)
Coloque o arquivo na pasta `mods` do **Minecraft 1.21.1 com NeoForge**.

Mod de Minecraft **NeoForge 1.21.1** (`mareeletrica`): hidrelétricas, armas, veículos, esportes, jogos (sinuca, arcade, boliche, golfe, minigolfe, pingue-pongue), skate, surfe e muito mais.

- Código: `src/main/java/br/mareeletrica`
- Recursos (modelos, texturas, sons): `src/main/resources`
- Scripts que geram modelos/texturas: `tools/`
- Testes visuais: `tests/visual053`
- Novidades de cada versão: `NOVIDADES_<versão>.md`

Compilar: `gradle build` → `build/libs/mare-eletrica-<versão>.jar`
