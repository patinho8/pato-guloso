# Maré Elétrica 0.78.0 — Combo das facas

- Atacando de novo com a faca em até 1,5 segundo, sai o **2º golpe**, com animação própria para cada faca:
  - **Karambit:** gancho horizontal cruzando a tela.
  - **Xeno Hunter:** golpe diagonal de cima para baixo.
  - **HRT3:** estocada girando a lâmina.
  - **Butterfly:** corte reto de costas da mão, da direita para a esquerda.
  - **Banana:** pancada de cima para baixo.
- O **3º golpe** seguido é uma finalização mais larga, com um giro. Depois o combo volta ao primeiro golpe.
- Cada golpe do combo tem um som um pouco diferente, e o rastro do corte acompanha: no 2º golpe ele vai para o outro lado e no 3º fica maior.
