# Maré Elétrica 0.81.0 — Recuo pesado nas armas grandes

As armas grandes agora têm um recuo enorme:

| Arma | Câmera sobe | Empurrão para trás |
|---|---|---|
| Barrett M82 | 2,6× mais | forte |
| Dragunov SVD | 2,2× mais | médio |
| Sniper de Precisão / Caçador | 1,6× mais | médio |
| M870 / SPAS-12 | 1,8× mais | leve |
| Saiga-12 | 1,6× mais | leve |
| M249 | 1,8× mais (sobe rápido na rajada) | quase nada |

- Cada tiro dessas armas **empurra o atirador para trás**, faz a **tela tremer** e a arma bate mais forte na mão.
- **Deitado ou com bipé** o recuo cai para cerca de 1/4 e quase não empurra. **Agachado** o recuo e o empurrão diminuem pela metade.
- Atirar com a Barrett em pé dá um pouco de fome.
- As outras armas não mudaram.
