# Maré Elétrica 0.60.0

## RPG com recuo
- Ao disparar, a câmera dá um coice para cima (~6° mirando, ~9° sem mirar) e treme por um instante.
- O tubo recua no ombro/na mão.
- O jogador é empurrado para trás pelo sopro traseiro (menos se estiver agachado; nada se estiver num veículo).
- O recuo só acontece quando o disparo sai de fato (sem recarga pendente e com míssil).

## Quadra de tênis menor
- **Tênis:** 80 x 58 → **60 x 40**.
- Corredores de duplas de 5 blocos.
- Linha de saque a 16 blocos da rede.

## Correções de texturas e ícones
- 142 ícones 3D de itens foram centralizados e ajustados para caber no slot. Antes alguns saíam para fora ou apareciam deslocados, por exemplo Danoninho, Elevador de Vórtice, Hangar de Veículos, Walkie-talkie, Óculos Térmicos, Base Portátil, lunetas, Drone e Ringue de Galos.
- A Turbina de Telhado agora mostra o rotor no ícone (antes só a base aparecia).
- Foram adicionados os nomes que faltavam das entidades Granada e Projétil DMT.
- Auditoria completa sem nenhum problema encontrado:
  - todos os modelos apontam para texturas existentes;
  - todos os blockstates apontam para modelos existentes;
  - todos os itens têm nome e modelo;
  - nenhum UV fora do intervalo.
